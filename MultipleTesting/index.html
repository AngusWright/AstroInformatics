Three distinct probabilities

For a threshold z, the local null tail probability is p = Φ(−z), or 2Φ(−z) for either sign. This is a false-positive probability at a prespecified location, not P(source is false | detection). For an individual cell, its observed p-value would use its observed z rather than the chosen threshold.

For N0 independent null locations, the family-wise error rate is P(V ≥ 1) = 1 − (1 − p)N0. The calculation uses log1p/expm1 to retain small probabilities. The expected number of false positives, E[V] = N0p, is a count and may exceed one.

The realised false discovery proportion (FDP) is V/(T+V), where T and V are the true and false discoveries in this one survey. FDR is the expectation of FDP over repeated surveys, conventionally assigning FDP = 0 to a run with no discoveries. The page labels an empty observed fraction “no discoveries”, not an estimated posterior probability. In the noise-only model, every discovery is false and FDR = FWER; with injected sources, FDR and FWER generally differ.

Assumptions and the browser extension

Each cell is one independent resolution element, not necessarily a camera pixel. PSFs and resampling correlate real pixels. Choosing thresholds, masks or extra searches after seeing the image changes the procedure.

The R lesson contains no real sources. Its default is retained. The optional extension independently marks each cell as a source with the specified probability and adds a fixed positive amplitude to its Gaussian noise. Truth is known only in this simulation. Global false-alarm calculations then condition on the realised number of null cells; no multiple-testing FDR-control procedure is being applied.

The browser uses its own seeded generator, not R's random stream. Changing area keeps overlapping linear-index cells fixed; changing threshold or tails never changes observations.

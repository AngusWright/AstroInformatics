Start with a pattern you cannot see

  1. Choose Hidden wave. The signal amplitude is 0.6, but each pixel has noise SD 4. Look for the two bright spots near (±9, ±5).
  2. Click a spot, or choose Select brightest non-DC pair. Keeping just that conjugate pair reconstructs a wave even though the original image looks like noise. Noise in those modes remains.
  3. Rewind, then play. Only the strength of the same noise field grows. Change kx or ky: the spots move, and the stripes change spacing or direction.
  4. Choose Two waves. Click each pair in turn to separate the two patterns. Set Function B to match Function A, then change its phase: amplitudes can reinforce or cancel.
  5. Try a Gaussian blob and vary its size: a narrower feature needs a wider range of frequencies. Compare square and circular apertures, a point, and two points.
  6. Choose Noise only. There is still a brightest pair. Repeat with new noise: its location changes. Peak picking alone does not establish a physical signal.

What is a k-mode?

A mode is a sinusoidal pattern with wave vector (kx, ky). Here k is measured in cycles across the whole image, not radians per pixel. Its perpendicular wavelength is 128 / √(kx2 + ky2) pixels. The stripes run perpendicular to the k-vector. A cosine at an integer k occupies a positive and a negative frequency; they are two halves of one real pattern, not two independent detections.

A complex coefficient records amplitude and phase

F(kx, ky) = (1/N²) Σx Σy I(x, y) exp[-2πi(kx x + ky y)/N]
I(x, y)  = Σkx Σky F(kx, ky) exp[+2πi(kx x + ky y)/N]
N = 128; power = |F|²; phase = arg(F)

There is no information loss when all complex coefficients are retained. The Fourier image is centred on the zero-frequency DC mode, which equals the image mean. Mean subtraction removes only DC. For real images F(−k) = F(k)*; pair filtering preserves this symmetry, so the inverse stays real. The reported cosine amplitude is 2|F|, except for DC and self-conjugate Nyquist modes, where it is |F|.

Phase changes where a wave lies without changing its individual power. Circularly shifting an entire image changes Fourier phase, not power; use a noise-free, single-function example to test this with the position controls. Shifting only one component relative to another, or to fixed noise, can change their interference. The phase display uses colour for angle and brightness for amplitude; phase where amplitude is negligible is not meaningful. Two superposed signals add as complex coefficients, so their powers do not generally add: overlapping modes interfere.

Why the hidden wave survives

The transform sums each pixel against a matching wave. A matching signal adds coherently; independent, zero-mean Gaussian noise partly cancels. With N2 pixels and noise SD σ, the expected noise power in each unremoved Fourier bin is σ2/N2. For an ordinary non-self-conjugate mode the noise SD in each fitted cosine/sine amplitude is √2 σ/N. No extra information has appeared: this is an efficient representation of the same pixels.

A single noise realisation has a mottled spectrum, not a perfectly flat one. Conjugate bins are dependent, and searching many possible frequencies increases the chance of a large noise peak. The displayed peak, amplitude and retained-energy fraction are descriptive diagnostics, not p-values or posterior detection probabilities. Coloured or correlated noise can itself make structured Fourier features; only independent white noise is simulated here.

Shapes, edges and sampling

A well-contained Gaussian has a Gaussian-like transform: compact spatial features have broad Fourier support. A square aperture gives a separable sinc-like pattern; a circular aperture gives circular, Bessel-like rings. A single pixel has flat power, and two pixels give interference fringes. These are discretely sampled functions, not exact continuous optical diffraction calculations; a broad Gaussian truncated by the image boundary need not have an exactly Gaussian spectrum.

The discrete transform treats the image as one tile of a periodic field. Integer wave frequencies join across the boundaries. Fractional frequencies do not, so their discontinuities spread power into neighbouring bins (spectral leakage). No taper or zero padding is applied. Spatial frequencies run from −64 to 63 cycles/image on each axis; the Nyquist boundary is the sampling limit, not a new independent negative/positive pair.

Size means Gaussian SD, disk radius, or square half-width; square boundary pixels are included, giving side length 2 × size + 1. Point sources occupy one pixel. Position controls circularly translate the sampled array, wrapping at the edge. Sharp low/high-pass cutoffs can introduce ringing. Selecting one mode discards all other structure and cannot remove noise at that same mode.

Reading the displays honestly

Real-space colours are linear and diverge about zero. The observation and reconstruction have separate, labelled ranges; the filtered image is not shown at the noisy image's much wider contrast. Neither range changes during playback. Log-power colours span five decades relative to a fixed reference Pref, using log10(1 + 105P/Pref)/log10(1 + 105); this changes the display only, not the transform. Linear power and amplitude-weighted phase are also available.

By this normalization, Σ|F|2 equals the mean squared image intensity (Parseval's theorem). The retained-energy fraction includes DC unless mean subtraction is enabled; it is not the fraction of true signal recovered. The profile also reports reconstruction error against the known, mean-adjusted input, which is available only because this is a simulation. An all-zero image has no defined energy fraction.

New noise changes the local seeded realisation; Reset restores the defaults. Changing functions, filters, phase, display or playback never resamples the noise. Playback scales one fixed noise field; it is not repeated observations or a growing exposure.

Try this

  1. Choose Matched surveys. Both independent validation sets follow the training measurement model; their accuracies can still differ by chance.
  2. Choose Calibration mismatch. Only target measurements move; the training sample and decision rule stay frozen.
  3. Switch to the original survey. Its validation results are unchanged. Switch back to inspect target errors.
  4. Choose Correct the calibration. The known shift is subtracted before applying the same rule. Compare with Unlabelled mean alignment, which estimates the shift from features alone.
  5. Choose Noise is not an offset. Even correct calibration cannot recover information erased by added measurement noise.

What is trained, shifted and evaluated?

The source training sample contains 200 stars and 200 quasars. Their intrinsic colour means are (−0.8, −0.4) and (0.8, 0.4), with independent Normal colour SDs 0.35 and 0.45. A linear discriminant uses the fitted class means and the average of their within-class sample covariance matrices, with equal class priors. The rule is wᵀx > wᵀ(μ̂₀ + μ̂₁)/2; exact ties are assigned to stars.

Two separate, balanced validation sets each contain 400 independent objects. New-survey measurements add the offset (δ, 0.4δ) and independent Normal noise of SD η in each colour. The labels do not change. Source data, source validation, target intrinsic colours and standardised target noise are cached by seed; changing calibration, noise, display or correction never redraws them.

This is general survey/domain shift. Changing the measurement process can change P(class | measured colour), so this is not restricted to the narrower mathematical definition of pure covariate shift.

Honest but deliberately limited adaptation

Known external calibration subtracts the specified simulated offset, as if supplied by an independent instrument calibration. It is an idealised benchmark with perfect calibration information, not something learned from target class labels. The source classifier is not retrained and target noise is not removed.

Unlabelled mean alignment subtracts mean(target features) − mean(source training features). It uses the unlabelled target batch, not its labels; evaluation is transductive on that same batch. This relies on a shared class mixture and an additive shift. Finite-sample fluctuations, different class proportions or a more complex measurement change can make it inaccurate or harmful. It is not guaranteed to improve accuracy.

The labelled target truth reveals evaluation errors only. Repeatedly choosing a correction after inspecting those accuracies would itself tune on validation labels; an actual deployment needs a separate final test set. Balanced classes and these simple Gaussian populations are not a realistic quasar survey.
